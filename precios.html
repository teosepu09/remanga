Información ReManga

Mejores precios

Un espacio pensado para encontrar mangas nuevos y usados, comparar publicaciones y elegir la opción que mejor se adapte a cada compra.

Los precios publicados serán definidos por cada vendedor según las características de sus productos. Las promociones y condiciones comerciales futuras se informarán cuando estén disponibles.

Cómo funciona el sistema de precios

Publicaciones de vendedores

Cada vendedor podrá establecer el precio de sus mangas teniendo en cuenta el estado, edición y características del producto.

Compará opciones

La plataforma busca facilitar la comparación entre distintas publicaciones para que puedas tomar una decisión informada.

Nuevo o usado

Las publicaciones indican el estado del manga para que puedas evaluar el producto antes de comprarlo.

Qué buscamos ofrecer

01

Transparencia

La información de cada publicación debería permitir conocer el precio y las condiciones del producto antes de avanzar.

02

Variedad

La presencia de diferentes vendedores puede generar distintas alternativas para un mismo título o colección.

03

Precios competitivos

ReManga busca construir un mercado donde la variedad de publicaciones favorezca precios atractivos y oportunidades para compradores y vendedores.

Promociones y ofertas

En el futuro podrán incorporarse herramientas como promociones, descuentos, publicaciones destacadas u otras formas de incentivar la compra y venta dentro de la plataforma.

Preguntas frecuentes

¿ReManga fija el precio de los mangas?

La idea del marketplace es que cada vendedor pueda establecer el precio de su publicación respetando las reglas que se definan para la plataforma.

¿Puede cambiar el precio de una publicación?

Las condiciones definitivas para modificar una publicación serán establecidas cuando esté disponible la gestión completa de ventas.

¿Habrá descuentos?

Es una posibilidad futura. Las promociones dependerán de las funcionalidades comerciales que se incorporen a ReManga.
